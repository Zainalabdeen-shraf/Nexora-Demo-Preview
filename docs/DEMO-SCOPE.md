# نطاق نسخة العرض

## الموجود في الديمو

- واجهة WPF عربية وتنقل موحد حسب وحدات العمل.
- إدارة محلية تجريبية للكروت والدفعات.
- كتالوج باقات وتكوينات مرتبطة بجهة إصدار.
- سجلات مبيعات تجريبية وشاشة نقاط بيع وتقارير.
- إعدادات عرض لمصادر المصادقة ومركز تقارير متعدد الأنواع.
- حفظ محلي لتفضيلات ومساحة الديمو.

## ليس جزءًا من هذا الإصدار

- لا يوجد اتصال إنتاجي بـ MikroTik/RouterOS أو RADIUS.
- لا توجد قياسات استخدام فعلية قادمة من الراوتر.
- بيانات المبيعات المضمنة تجريبية وليست إثباتًا لمعاملات مالية حقيقية.
- إرسال مهمة طباعة إلى Windows لا يؤكد خروج الورق فعليًا.
- لا تُعد سجلات الديمو سجل تدقيق إنتاجيًا مركزيًا.

تُذكر هذه الحدود للحفاظ على وضوح المراجعة؛ لا تُستخدم أي بيانات توضيحية لادعاء تشغيل حقيقي للشبكة.
