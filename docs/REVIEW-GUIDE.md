# مراجعة نسخة Nexora Demo

## ما المطلوب من المراجع؟

1. فتح البرنامج والتحقق من أن التنقل يعكس تقسيم الوحدات الجديد.
2. مراجعة وحدة مستخدمي الشبكة الموحدة، مع اعتبار "النشطين" عرضًا لحالة الجلسة لا نوع حساب مستقلًا.
3. تجربة اختيار جهة الإصدار قبل تكوين الدفعة.
4. مراجعة فصل تعريف الباقة التجاري عن التكوين المرتبط بـ HotSpot أو User Manager.
5. مراجعة تدفق الطباعة والمبيعات ومركز التقارير كلٌّ بحسب بياناته.
6. إرسال ملاحظات قابلة لإعادة الإنتاج مع لقطة شاشة عند الحاجة.

## مسار العمل في GitHub

- التغييرات الجديدة تُنفذ على فرع واضح مثل `feature/reports-center-filters` أو `demo/network-users-navigation`.
- افتح Pull Request نحو `main` بدل تعديل `main` مباشرة.
- انتظر نتيجة `Windows Build & Demo Package` قبل المراجعة.
- دوّن هدف التغيير، وسيناريو الاختبار، واللقطات ذات الصلة في وصف الـ PR.
- لا تُدمج التغييرات التي تفشل في البناء أو تغير ملفات خارج نطاقها دون مراجعة.

## تشغيل ملف الإصدار

بعد نجاح سير العمل، يمكن تنزيل `Nexora-Demo-Preview-win-x64.zip` من تبويب Actions (للمستخدمين الذين لديهم صلاحية للمستودع). أما الإصدارات الموسومة `demo-vX.Y.Z` فتنشئ Release تجريبيًا قابلاً للتنزيل.
