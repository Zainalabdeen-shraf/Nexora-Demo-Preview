# Nexora — خريطة الوحدات

| مدخل القائمة | المسؤولية | الصفحات الحالية |
|---|---|---|
| الرئيسية | ملخص سريع ومداخل العمل | مؤشرات الكروت والمبيعات وروابط انتقال سريعة |
| مستخدمو الشبكة | واجهة واحدة لجميع سجلات الحسابات | كل الحسابات، النشطون، غير النشطين، تصفية HotSpot وUser Manager |
| الكروت والدفعات | دورة الإصدار والمخزون | إصدار الكروت، إدارة الكروت، إدارة الدفعات |
| الباقات | التعريف التجاري والتكوينات الخاصة بكل مصدر | الكتالوج، ربط HotSpot، ربط User Manager |
| المبيعات ونقاط البيع | سجلات البيع وتحليل نقاط البيع | الملخص، المعاملات، تجميع نقاط البيع |
| الطباعة والتصميم | تجهيز المعاينة وإرسال مهام الطباعة | قائمة الطباعة، معاينة الكرت، اختيار الطابعة |
| الشبكات ومصادر المصادقة | إعدادات كل طريقة مصادقة | نظرة عامة، HotSpot، User Manager |
| مركز التقارير | قراءة سجلات الوحدات دون تكرار منطقها | الكروت، الدفعات، المبيعات، الطباعة، الإجراءات، طلبات المزامنة، الاستخدام |
| الإعدادات والصيانة | تهيئة مساحة العمل | الإعدادات العامة، الموقع والهوية، النسخ الاحتياطي، الصيانة |

## قواعد الفصل

1. إدارة حسابات مستخدمي الإنترنت موحّدة. «النشطون الآن» عرض للحسابات ذات حالة الاستخدام المسجلة، وليس مجموعة حسابات أخرى.
2. كل دفعة لها جهة إصدار محددة. يظل HotSpot وUser Manager مستقلين تقنيًا.
3. كتالوج الباقات مشترك تجاريًا؛ التكوين الفني مرتبط بكل جهة إصدار ولا يُفترض أنه قابل للتبادل.
4. إنشاء الكرت، تجهيز الطباعة، إرسال مهمة للطابعة، البيع، وطلب المزامنة حالات مختلفة ولا تُحسب إحداها مكان الأخرى.
5. التقارير تستخدم سجلات الوحدات الحالية. تقرير الجلسات والاستهلاك لا ينشئ قياسات غير متوفرة.
